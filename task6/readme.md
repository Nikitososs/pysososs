# Steam Sales Historical Dataset

Датасет со статистикой по скидкам игр в steam

## Содеражание датасета

- Название игры
- Рейтинг игры
- Количество обзоров игры
- Текущий процент скидки
- Текущая цена в евро
- Первоначальная цена в евро
- Дата выхода игры
- Доступность на windows
- Доступность на linux
- Доступность на macOS
- Временная метка получения информации

## Применение датасета

- **Анализ динамики скидок** во времени
- Исследование **стратегий ценообразования** игровых издателей
- **Сравнение ценовой политики** между различными играми
- Прогнозирование **сезонных распродаж**
- Анализ корреляции между **рейтингом игры и скидочной активностью**
- Изучении **кросс-платформенной доступности** игр
