# Steam Sales Historical Dataset
Датасет со статистикой по скидкам игр в steam
## Содеражание датасета
- Название игры
- Рейтинг игры
- Количество обзоров игры
- Текущий процент скидки
- Текущая цена в евро
- Первоначальная цена в евро
- Дата выхода игры
- Доступность на windows
- Доступность на linux
- Доступность на macOS
- Временная метка получения информации
